     맞바꿈이다.** **다음에 학습을 설계할 때:** 출발은 운영 가중치, 앞쪽을 얼리는 것부터 · 구조나 사전학습을 바꾸기 전에 responder·cone
     라벨부터 늘릴 것(늘린 뒤 얼린 갈래의 epoch 수를 다시 잴 것) · 한 번 재서 0.04
     안쪽인 차이는 seed 를 바꿔 다시 볼 것 · 운영 가중치 쪽 수치는 라벨이 그 가중치의 자동 라벨에서 나와 유리하게 재지니, 따로 라벨한
     평가셋이 생기면 다시 잴 것.
