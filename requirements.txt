# --- PyTorch (CUDA 13.0 / Blackwell sm_120) ---
# 이 파일보다 **먼저** cu130 인덱스에서 받을 것 (저장소 폴더에서, .venv 의 pip 로):
#   .venv\Scripts\python.exe -m pip install torch==2.14.0+cu130 torchvision==0.29.0+cu130 --index-url https://download.pytorch.org/whl/cu130
# 아래는 +cu130 까지 고정했다 (11-01). PyPI 의 Windows 빌드(torch 2.14.0 win_amd64 는 124MB 짜리 CPU 빌드)는
# 이 고정을 만족하지 못해서, 순서를 바꿔 이 파일부터 깔면 CPU 빌드가 조용히 들어오는 대신 'No matching
# distribution' 으로 멈춘다. 이미 CPU 빌드가 깔렸으면 위 명령을 다시 돌리면 cu130 빌드로 바뀐다(+cu130 을 적었기
# 때문 — 그냥 ==2.14.0 이면 '이미 설치됨' 으로 넘어간다). 버전을 빼고 받으면 인덱스의 최신(10-31 에
# 2.14.1+cu130)이 깔려 이 고정과 어긋난다.
torch==2.14.0+cu130
torchvision==0.29.0+cu130
